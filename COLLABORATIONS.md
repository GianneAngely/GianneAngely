# Collaborations

Most of my team work does not show up on my GitHub profile, because it either lives in someone else's repository or sits in a private one. This page is the full list.

Commit counts below are the real numbers from the GitHub API. Private repositories are marked, and I only link to something when that link actually works for you.

---

## RANTAU — Ruang Temu Anak Perantau

**With** [@OnlyOneArthur](https://github.com/OnlyOneArthur) · **24 commits** · public

A web platform for students and workers living away from home: a kost finder with an interactive map, a roommate matcher scored on lifestyle compatibility, a shared bill splitter, and a community forum. Our team entry for the PRISMA Competition 2025.

[Repository](https://github.com/GianneAngely/Prisma-Competition-2025-Rantau) · [Live demo](https://rantau-website.vercel.app)

## UPTERRA

**With** [@OnlyOneArthur](https://github.com/OnlyOneArthur) · **14 commits on `main`** · private

An eco-tech waste management app. I built the Gemini Live integration: the AI camera scan that identifies household and electronic waste, and the realtime voice and video assistant on top of it.

[Live demo](https://upterra.vercel.app) — the repository is private, so it is not publicly viewable.

## Dermalyze Expert System

**With** [@OnlyOneArthur](https://github.com/OnlyOneArthur) · **5 commits** · public

A rule-based expert system for early skin lesion risk screening, using Forward Chaining inference and Certainty Factor reasoning over a JSON knowledge base. A student project, not a medical tool.

[Repository](https://github.com/GianneAngely/dermalyze-expert-system)

## Strukly AI for UMKM

**With** [@Alaika10](https://github.com/Alaika10), [@yahya16-rey](https://github.com/yahya16-rey), [@SicheateR](https://github.com/SicheateR), [@zahra28sabila-jpg](https://github.com/zahra28sabila-jpg) · **6 commits on the `Model-AI` branch** · public

A receipt-reading AI for small businesses. I worked on the classifier training and the JSON inference output.

My commits are on the `Model-AI` branch and have not been merged into the default branch yet, so GitHub does not list me under Contributors.

[Repository](https://github.com/Alaika10/strukly_AI_UMKM)

## The Deadline Warrior

**With** [@OnlyOneArthur](https://github.com/OnlyOneArthur) · **4 commits** · private

A survivor / bullet-heaven roguelite set inside a computer, built in Processing 4. You play a student fighting off five kinds of distraction enemies plus a boss while a deadline counts down.

The repository is private and the game is not published anywhere yet.

## A note on the numbers

Commit counts come from the GitHub contributors API, which only counts the default branch. That is why Strukly shows zero contributors for me despite the work being there, and it is the reason several of these projects were invisible on my profile until I turned on private contribution display.
